CDQ分治学习笔记

CDQ分治 学习笔记

陈丹琦恐怖如斯，插头DP难评

CDQ分治主要用与解决三维偏序问题，是一种离线算法。

部分数据结构题目，可以将修改转化为时间上的偏序，利用CDQ分治来解决。在加上分治写法灵活，可中序遍历优化DP，也可以后序遍历计数求值，这些都是后话了。

CDQ核心思想

二维偏序

给出 nnn 个有序对 (a,b)(a,b)(a,b), 求所有 (i,j)(i,j)(i,j) 的个数，满足 i≠j,ai≤aj，bi≤bji\not = j , a_i \le a_j，b_i \le b_ji=j,ai​≤aj​，bi​≤bj​。

使其中一维表示位置，则可以产生我们经典的逆序对 (顺序对?) 问题。
其中有一种解法使用树状数组，先双关键字排序和离散化，则第一维有序，再从前往后扫，树状数组得出前面小于bib_ibi​的个数。

但是，我们也来强行铺垫一波，还有第二种做法——归并排序(学会再来)。

在这个中间产物中，需要的 aaa 有序，bbb 有序都得到了部分的满足，可以利用这个中间状态来求解。

只要固定了 (i,j)(i,j)(i,j) 中的 jjj，再找合适的 iii，就可以不重不漏的统计。

由于是分治过程，左右子区间分别统计，需要在后序遍历中，利用子区间的有序来统计跨区间的答案。分别对于每个右区间的 jjj，统计左区间的 iii，可以利用归并时的双指针，在 jjj 之前排完的 iii都满足条件 (因为是以b为关键字排的)。

时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)

空间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)

▶
如何证明不重不漏呢？

考虑到在初始状态下 aaa 有序时，每个元素的位置唯一，设为xjx_jxj​，则只有 ≤xj\le x_j≤xj​ 的位置上的元素才有可能与 jjj 结合成一对 (i,j)(i,j)(i,j)，在不断二分时，右区间统计左区间，而分治中不同的左区间拼凑成了 [1,xi)[1,x_i)[1,xi​) 这个待求区间。

三维偏序

给出 nnn 个有序对 (a,b,c)(a,b,c)(a,b,c), 求所有 (i,j)(i,j)(i,j) 的个数，满足 i≠j,ai≤aj，bi≤bj，ci≤cji\not = j , a_i \le a_j，b_i \le b_j，c_i \le c_ji=j,ai​≤aj​，bi​≤bj​，ci​≤cj​。

基于二维偏序的两种解法，发现树状数组可以在其中一维完全有序的前提下，解决第二维的统计；归并排序可以用中间状态的部分有序，和正确统计答案的方式，在右区间统计左区间答案。

CDQ分治把两者结合了起来。树状数组可以方便地存储值域，统计个数(类似桶排)，直接削掉一维；归并排序能用双指针和分治解决子问题来降低一维。由于树状数组更灵活，把它放在里层统计第三维，外层先用归并排序降低两维，这样树状数组就利用上了左右子区间的第二维有序。

时间复杂度：分治划分了 log⁡n\log nlogn 层，每一层合起来都是整个区间 nnn，也就是说双指针扫了 O(nlog⁡n)O(n\log n)O(nlogn) 次，使用树状数组是 O(log⁡n)O(\log n)O(logn) ，所以总复杂度是 O(nlog⁡2n)O(n\log^2 n)O(nlog2n)

空间复杂度：O(n)O(n)O(n)

CDQ分治优化DP

简洁的题面：给出 nnn 个有序对 (a,b,c)(a,b,c)(a,b,c), 找出一个序列，满足任意 i≤ji \le ji≤j，有api≤apj，bpi≤bpj，cpi≤cpja_{p_i} \le a_{p_j}，b_{p_i} \le b_{p_j}，c_{p_i} \le c_{p_j}api​​≤apj​​，bpi​​≤bpj​​，cpi​​≤cpj​​。尝试最大化其长度。

看起来像是一个三维偏序，不过是求最长上升子序列。

还是从低维的开始分析：

一维的就十分简单，经过简单的分析可以看出，排序后就可以得到最优解，直接 O(1)O(1)O(1) 输出答案 ans=nans = nans=n。

二维的就需要排序，就转化成了经典的 LISLISLIS 问题，设 f[i]f[i]f[i] 为以第 iii 项为结尾的 LISLISLIS 的长度。则有 f[i]=max⁡{f[j]}+1(j<i，bj≤bi)f[i]=\max\{f[j]\} + 1 (j<i，b_j \le b_i)f[i]=max{f[j]}+1(j<i，bj​≤bi​)。只要求出已接好的序列中的前缀最大值即可，众所周知可以用单调性来做。

为了和一般的CDQ较为贴近，我们用树状数组来做，众所周知树状数组是可以支持求前缀最大值的。

那么，我们只要查询 bj≤bib_j \le b_ibj​≤bi​ 前缀中的 f[j]f[j]f[j] 最大值来更新 f[i]f[i]f[i]，在用 f[i]f[i]f[i] 更新树状数组就可以了。

代码实现

再到三维，参考二维的分析，发现 f[i]f[i]f[i] 的转移是类似线性递推的结构，后面的状态依赖于前面的结果。如果前面的状态没有转移完，后面无法转移。

这与之前的结构不同，之前是大区间依赖小区间，左区间里的答案之后在大区间更新时会改变，我们却在这时用它来更新右区间，如此就不能保证无后效性，我们需要中序遍历而不是后序遍历。

四维偏序(CDQ套CDQ)

三维已解决，我们能否解决四维甚至更高维的偏序呢？

给出 nnn 个有序对 (a,b,c,d)(a,b,c,d)(a,b,c,d), 求所有 (i,j)(i,j)(i,j) 的个数，满足 i≠j,ai≤aj，bi≤bj，ci≤cj，di≤dji\not = j , a_i \le a_j，b_i \le b_j，c_i \le c_j，d_i \le d_ji=j,ai​≤aj​，bi​≤bj​，ci​≤cj​，di​≤dj​。

▶
思路引导

主要有两个函数：

cdq1：在 aaa 有序时做标记 opopop 的工作，再递归进入cdq2。

cdq2：在 bbb 有序时做双指针，统计答案。

从一维到三维，都是不断叠buff来削去每一维，树状数组配双指针的结构已经很固定，可以解决其中两维。

而外层只是一个提前的排序，再分治划分子区间来保证左右区间的整体关系，其功能类似于分配角色，使其中的数处在右区间时可以做查询，来统计左区间的配对，如果不排序，就不能默认地用右区间统计左区间了。

受此启发，我们将前两维 (a,b)(a,b)(a,b) 的排序用作划分子区间的角色(插入/查询)，对应增加Node一个状态 op(0/1)op(0/1)op(0/1)，前两维中第二维 bbb 仍可以像之前一样作为关键字排序，左右区间划分完后，默认是右区间做查询。

为了保证右区间按 bbb 排序后，查询元素仍满足第一维 aaa 的偏序，要在排 bbb 之前先用 aaa 来确定 opopop，也就是谁做插入，谁做查询，再排好序进入cdq2。最后cdq2中只有 op=1op=1op=1 的右区间元素可以查询，op=0op=0op=0 的左区间元素可以插入。其他元素不在这次划分的考虑范围内。

▶
我知道很抽象

可以把后两维看成一类(可直接解决类)，前面两维看成第二类(隐形解决类)

后一类中每一维做一次划分，提前标记元素它满足了这一维的偏序。

Node中 op1(0/1)op_1(0/1)op1​(0/1) 表示第一维 aaa 排序中它被分到了左/右区间。左区间里 aaa 比右区间小，可以做插入；右区间 aaa 比左区间大，可做查询。在cdq1中按 aaa sort后，左边标记0，右边标记1。

op2(0/1)op_2(0/1)op2​(0/1) 表示同理，可以看出能配对的是前两维都是左比右小的，只有同时满足 op1=0,op2=0op_1=0,op_2=0op1​=0,op2​=0 才可以做插入，同时满足 op1=1,op2=1op_1=1,op_2=1op1​=1,op2​=1 的才可以做查询。

只不过cdq2里第二类最后的一维划分完后直接做双指针，此时直接是要右区间查左区间，而这一维刚排完序，恰好满足左区间小于右区间，就不需要再用一个 opopop 去标记了。

细节：

一.排序要稳定。

我们是用标记的形式来记录 aaa 的相对大小，但在cdq2中，应像普通cdq一样，如果有 ccc 的相同元素，把插入放在查询前，因为 bbb 是 左区间 ≤\le≤ 右区间 已经满足，也就是说要让b,c都相同时，op=0op=0op=0 的元素在 op=1op=1op=1 的元素前面。在排 b,cb,cb,c 之前 opopop 其实是满足这个条件的，如果排序不稳定，则这个顺序在之后 b,cb,cb,c 相同时，谁在前面就不一定了。
